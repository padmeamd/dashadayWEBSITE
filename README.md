# DashaDay — Midnight Archive

Official site for DashaDay: music, videos, visuals, and contact.

## Local development

Requires [Node.js](https://nodejs.org/) (LTS recommended).

```sh
npm install
npm run dev
```

The dev server runs at [http://localhost:8080](http://localhost:8080).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start Vite dev server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## Stack

- Vite
- TypeScript
- React
- React Router
- Tailwind CSS
- shadcn/ui
- Framer Motion

# Dasha Day Cinema — план

Кинотеатр на `heydashaday.com/cinema`: бесплатный эпизод и трейлеры для всех,
ранние серии и дополнительные материалы по подписке £4/месяц.

Этот раздел — план, а не описание готового. Ничего из перечисленного ещё
не написано.

## Что уже есть и чего нет

| | состояние |
|---|---|
| React 18, Vite 5, React Router 6, Tailwind | работает |
| Cloudflare Pages | работает, деплой из `main` |
| **Серверная часть** | **её нет вообще** — сайт полностью статический |
| **Вход, база, платежи** | нет |
| Каталог серий | 2 записи в `src/data/series.ts`, без полей для кинотеатра |

Серверной части нет — и это главное. Кинотеатр без неё невозможен: проверять
право на просмотр можно только на сервере, в браузере эта проверка ничего
не значит.

## Из чего собирать

| | зачем | цена |
|---|---|---|
| **Cloudflare Workers** | защищённое API рядом с сайтом | бесплатно до 100 000 запросов в день |
| **Supabase** | вход через Google и база | бесплатно до 50 000 активных в месяц |
| **Stripe** | подписка и разовые покупки | комиссия с платежа |
| **Cloudflare Stream** | хранение и раздача видео | $5 за 1000 минут хранения в месяц, $1 за 1000 минут просмотра |

Выбор не случайный: Workers живут в том же Cloudflare, что и сайт, —
отдельный хостинг и отдельный домен не нужны.

### Сколько это будет стоить

Считаю на её цифрах. Серия примерно 2 минуты, в сезоне скажем 10 серий плюс
трейлеры — около 25 минут. Хранение: **меньше доллара в месяц**.

Просмотр: 100 подписчиков, каждый смотрит 25 минут — 2500 минут, **$2,50**.
При 500 подписчиках — около $12.

Supabase и Workers на этих объёмах бесплатны. То есть инфраструктура
кинотеатра стоит единицы долларов, пока аудитория не вырастет в разы.

**Оговорка:** бесплатный проект Supabase засыпает после недели без обращений.
Для живого сайта это не проблема, но на этапе разработки может удивить.

## Вход через Google

Supabase Auth даёт его из коробки, писать OAuth руками не нужно.

```
браузер → Supabase Auth → Google → возврат с сессией
                ↓
         строка в auth.users
```

Настройка — в консоли Supabase, раздел Authentication → Providers → Google.
Понадобится OAuth-клиент в Google Cloud: **тот же проект, где уже живёт
YouTube**, второй заводить незачем.

Кроме Google — вход по ссылке на почту, без пароля. Пароли, которые можно
забыть или потерять, лучше не заводить вовсе.

**Правило, которое нельзя нарушать:** сессия в браузере говорит, кто человек,
но не говорит, что ему можно. Право на просмотр проверяется на сервере при
каждом запросе видео.

## Backend: шесть эндпоинтов

Всё в `functions/` — Cloudflare Pages подхватывает эту папку автоматически.

| метод | что делает |
|---|---|
| `POST /api/checkout` | создаёт сессию Stripe. **Цену выбирает сервер**, не браузер |
| `POST /api/stripe/webhook` | проверяет подпись, записывает id события, обновляет доступ |
| `GET /api/me/entitlements` | что этому человеку сейчас доступно |
| `POST /api/video-token` | проверяет доступ → выдаёт короткоживущий токен на видео |
| `POST /api/billing-portal` | ссылка на управление подпиской |
| `PUT /api/watch-progress` | где человек остановился |

### Таблицы

```
users            id, email, created_at, auth_provider
subscriptions    user_id, stripe_customer_id, status, current_period_end
entitlements     user_id, product_id, source, valid_until
episodes         id, number, title, stream_uid, release_at, public_at, free
purchases        user_id, stripe_payment_id, product_id, status
watch_progress   user_id, episode_id, position_seconds, updated_at
webhook_events   provider_event_id, type, processed_at, outcome
```

`webhook_events` — не бюрократия. Stripe доставляет одно событие несколько
раз, и без записи id подписка продлится дважды с одного платежа.

У `episodes` два поля дат: `release_at` — когда серия открывается подписчикам,
`public_at` — когда становится бесплатной. Вся модель «сначала подписчикам,
через неделю всем» держится на этих двух числах.

## Плеер

Cloudflare Stream даёт свой, и для начала этого достаточно.

| вариант | за | против |
|---|---|---|
| **Stream Player** (`@cloudflare/stream-react`) | ничего не писать, HLS, субтитры, качество — всё само | вид почти не настраивается: цвет и постер |
| Vidstack или Video.js + HLS.js | полный контроль над видом | самим делать субтитры, выбор качества, восстановление после обрыва |

**Начинать со Stream Player.** У сайта выраженная эстетика, и стандартный плеер
в неё не вписывается — но переделывать внешность плеера до того, как кто-то
купил подписку, значит решать не ту задачу. Компонент меняется на свой
за день, когда станет ясно, что он того стоит.

Чего не делать ни в каком варианте: **не обещать защиту от записи экрана.**
Её не существует. Приватные видео и короткоживущие токены останавливают
случайное распространение ссылок, не более того.

## Порядок работ

| # | что | дней |
|---|---|---|
| 1 | Каркас: `/cinema`, страница серии, `/account`, сетка на телефоне | 2–3 |
| 2 | Supabase, вход через Google, таблицы, RLS | 2 |
| 3 | Stream: загрузить серию, приватная выдача, `POST /api/video-token` | 2 |
| 4 | Stripe: подписка, вебхуки, портал управления | 3–4 |
| 5 | Перенос существующих подписчиков Buy Me a Coffee | 2–5 |
| 6 | Бета на 10–20 человек, юридические страницы | 2–3 |

Всего **13–19 рабочих дней**. Оценка, не обещание срока.

### Что должно работать до запуска

- Без подписки платный поток недоступен — проверено запросом в обход браузера
- Повторный вебхук не выдаёт доступ дважды
- Подписку можно отменить самому, доступ закрывается по окончании периода
- Отклонённая карта, возврат, смена почты — все пройдены на тестовых ключах
- Политика и условия обновлены: там появятся деньги, возвраты и НДС

## Два решения, которые нужно принять заранее

**Юрисдикция.** Stripe привязан к стране продавца, и от неё зависят НДС,
отчётность и права потребителя. Пока это не решено, платёжный код пишется
нейтрально — переписывать интеграцию дважды дороже, чем подождать.

**Существующие подписчики Buy Me a Coffee.** Нужно выяснить, даёт ли сервис
выгрузку участников. Автоматически доступ не перенесётся: это две независимые
платёжные системы, которые друг о друге не знают. Плана «просто подключим»
не существует — и брать с человека деньги дважды нельзя.
